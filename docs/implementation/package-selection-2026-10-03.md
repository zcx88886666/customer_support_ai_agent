# Multi-package logistics clarification — 2026-10-03

Chat accepts an optional `shipment_id`. When an owned order has multiple packages and the question needs logistics facts, the coordinator asks the customer to choose a package and returns only that order's shipment IDs. A later turn can supply the choice; the pending intent and order remain scoped to that customer's thread. The service rejects a nonexistent or other-order package with 404, clears a prior package choice when the order changes, and binds the selected package to the read-only specialist task. The specialist and coordinator verify its order ownership, source ID, current status, and delivery timestamp before answering. The web UI loads shipments with the order and shows a package selector when needed.
